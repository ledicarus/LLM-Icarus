LLM Icarus - third-party software and models
=============================================

LLM Icarus runs entirely on your PC. It is built from, and downloads, the open-source
components below. Each keeps its own license. This list is a summary; check each project
for the full, current license text.

Bundled with the installer
--------------------------
Node.js (runtime)                    MIT license                      https://nodejs.org
Microsoft Edge WebView2 SDK          BSD-style license (see licenses\WebView2)   https://developer.microsoft.com/microsoft-edge/webview2
  - shows the app window; uses the WebView2 Runtime that is part of Windows 10/11 and Edge.

  - CUDA build also contains NVIDIA CUDA runtime libraries, redistributed under the
    NVIDIA CUDA Toolkit license terms for redistributable files.
Python (embeddable package)          Python Software Foundation License   https://www.python.org
faster-whisper / CTranslate2         MIT license                      https://github.com/SYSTRAN/faster-whisper
PyAV, ONNX Runtime, tokenizers       BSD / MIT style licenses         (installed as dependencies by pip)
NVIDIA cuBLAS / cuDNN (pip wheels)   NVIDIA proprietary license       https://developer.nvidia.com
PyTorch                              BSD-3-Clause                     https://pytorch.org
diffusers, transformers, accelerate, safetensors     Apache-2.0       https://huggingface.co
